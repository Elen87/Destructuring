Destructuring - Извлечение спец.атак

Функция extractSpecialAttacks(character)

Извлекает из объекта персонажа массив спец.атак с полями:

  • id - идентификатор атаки
  • name - название атаки
  • icon - иконка атаки
  • description - описание атаки (или "Описание недоступно")

Откройте консоль браузера (F12), чтобы увидеть результаты работы функции.
